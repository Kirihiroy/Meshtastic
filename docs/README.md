# Документация проекта Meshtastic (Android)

Этот каталог содержит рабочую документацию по текущей реализации Android-клиента для устройств Meshtastic.

## Текущая версия

**v0.2.0** (июнь 2026) — полный редизайн UI под стиль оригинального Meshtastic-Android, чат с пузырями и группировкой, меню Настроек из 10 разделов.

## Содержание

- [`SETUP.md`](SETUP.md) — требования и установка окружения
- [`USAGE.md`](USAGE.md) — как пользоваться приложением (Соединение, Ноды, Чат, E2E ЛС, Настройки)
- [`FEATURES.md`](FEATURES.md) — реализованные и планируемые функции
- [`ARCHITECTURE.md`](ARCHITECTURE.md) — структура модулей и поток данных
- [`CONFIGURATION.md`](CONFIGURATION.md) — настройки сети и безопасности (PSK)
- [`TROUBLESHOOTING.md`](TROUBLESHOOTING.md) — типовые проблемы и решения
- [`SCREENSHOTS.md`](SCREENSHOTS.md) — шаблон для скриншотов и описаний экранов
- [`GLOSSARY.md`](GLOSSARY.md) — термины и сокращения
- [`FAQ.md`](FAQ.md) — частые вопросы (в т.ч. как написать в личку через E2E)
- [`CHANGELOG.md`](CHANGELOG.md) — изменения по версиям

## Как читать

1. Начните с [`SETUP.md`](SETUP.md) и [`USAGE.md`](USAGE.md).
2. Для понимания внутренней логики — [`ARCHITECTURE.md`](ARCHITECTURE.md).
3. При проблемах — [`TROUBLESHOOTING.md`](TROUBLESHOOTING.md) или [`FAQ.md`](FAQ.md).

## Структура UI (для быстрой ориентации)

5 вкладок в нижней навигации:

| # | Вкладка | Что делает |
|---|---|---|
| 1 | **Чат** | Общий канал mesh-сети |
| 2 | **Ноды** | Список узлов + встроенный статус-баннер |
| 3 | **Карта** | *(в разработке)* |
| 4 | **Настройки** | Меню из 10 разделов конфигурации |
| 5 | **Соединение** | Выбор и подключение к устройству |
| – | **E2E ЛС** | Личные сообщения (отдельная вкладка) |

> Раздела «Статус» больше нет — его метрики в баннере на «Нодах».
