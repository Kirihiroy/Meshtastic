## [0.2.0] - 2026-06-22

Большое обновление UI: визуальный язык приведён к оригинальному
Meshtastic-Android, добавлены чат с пузырями и группировкой,
полное меню Настроек из 10 разделов, экран соединения переработан.

### Added (Добавлено)

#### Чат
- Шапка с подзаголовком «Канал: LongFast · участников: N»
- Пузыри сообщений в стиле мессенджера: входящие слева (тёмно-сине-серый),
  исходящие справа (тёмно-синий)
- **Группировка сообщений**: подряд от одного отправителя в пределах
  5 минут — без повторения аватара/имени, скруглённый пузырь
- **Цветной аватар** с короткими инициалами для первого сообщения в группе
  (цвет генерируется HSV-хешем `senderId`)
- **Статус доставки** для исходящих: ⏱ SENDING / ✓ SENT / ✓✓ DELIVERED / ⚠ FAILED
- **Hops chip** в углу пузыря для входящих из mesh-сети
- **FAB «↓ N новых»** при прокрутке вверх — тап скроллит к низу
- **Контекстное меню** по долгому нажатию (Скопировать / Ответить / Удалить локально)
- Скруглённое поле ввода с иконкой скрепки + круглая зелёная кнопка отправки
- Разделитель даты в виде pill-chip (Сегодня / Вчера / 13 мая 2026)

#### Соединение (бывшее «Подключение»)
- Полностью переработан в стиле оригинального Meshtastic-Android
- Большая информационная карточка устройства с пиктограммой router
- **Segment-control транспортов**: Bluetooth / Сеть / COM-порт
  (только Bluetooth функционален, остальные — placeholder)
- Список «Сопряжённые устройства» с radio-button одиночного выбора
- Одна **state-aware кнопка** действия:
  Сканирование → Остановить → Подключиться → Подключение… → Отключиться
- Статус-чип внизу экрана
- Авто-остановка сканирования через 8 секунд

#### Ноды (бывшие «Узлы») — встроенный статус-баннер
- Заменил отдельный экран «Статус» (StatusFragment удалён)
- Цветной индикатор состояния (зелёный/жёлтый/красный/серый)
- Текст состояния + время последнего RX
- Строка метрик «Батарея X% · SNR X.X · vX.X.X»
- **Тап по баннеру** = `requestConfigManual()` — переотправляет
  `want_config_id` если устройство «зависло»

#### Меню Настроек — 10 разделов
- Главный экран — список разделов в стиле Meshtastic-Android
- **LoRa**: регион, пресет модема, hop limit, TX мощность, переключатели
- **Каналы**: список 8 слотов (PRIMARY + 7 SECONDARY/DISABLED) + редактор канала
- **Безопасность**: E2E pubkey (копирование в clipboard), 3 admin-ключа, is_managed
- **Пользователь**: длинное/короткое имя, роль (11 вариантов), HAM
- **Устройство**: rebroadcast mode, NodeInfo period, switches
- **Местоположение**: GPS mode, broadcast, Fixed/Smart
- **Питание**: power saving + 3 таймера
- **Сеть**: Wi-Fi (SSID/PSK), NTP, Ethernet
- **Дисплей**: screen timeout, units, flip/12h/bold
- **Bluetooth**: enabled, pairing mode, fixed PIN
- Раздельные секции `SettingsStore.loadWithX/saveX` для каждого экрана

#### Модель данных
- `Message`: добавлены поля `deliveryStatus` (enum) и `hopsAway`
- `NodeInfo`: добавлены `hwModel`, `role`, `voltage`, `chUtilization`,
  `airUtilTx`, `altitude`, `hasPsk`
- `ChannelDraft`: новый POJO для одного канала (index/name/psk/role)
- `SettingsDraft`: расширен под все 10 разделов (~50 полей)
- `MeshProtoParser` / `MeshConnectionRepository.convertNode()`:
  извлекает все новые поля из protobuf

### Changed (Изменено)

- **Bottom navigation**: пункт «Подключение» → «Соединение»,
  «Узлы» → «Ноды», пункт «Статус» удалён
- `MainActivity.showFragment()`: при смене bottom-nav вкладки очищает
  весь back stack (для корректной работы sub-фрагментов настроек)
- Карточка ноды (`item_node.xml`): полная переработка под стиль оригинала
  (бейдж, замок, метрики, hw-model/role/!ID)
- Меню `bottom_nav_menu.xml`: убран `nav_status`, переименован `nav_connection`

### Fixed (Исправлено)

- **Пустой список нод после подключения** — `requestConfig` обходит
  `sendToRadio` и пишет напрямую в BLE, чтобы избежать race с
  асинхронным `LiveData.postValue` (state ещё CONNECTING на момент
  отправки want_config_id)
- **Compile error в Java 11**: `DevicesAdapter` сделан `static class`
  (вложенный `interface OnClick` не разрешён в non-static inner class)
- LF→CRLF normalization в drawable XML под Windows

### Removed (Удалено)

- `StatusFragment.java` + `fragment_status.xml` — метрики перенесены
  в баннер на экране «Ноды»
- Пункт «Статус» из bottom navigation
- Все строки `status_*` из `strings.xml`

### Security (Безопасность)

- E2E-ключ хранится защищённо: PKCS#8 обёрнут AES-256-GCM,
  AES-ключ в Android Keystore (`E2eKeyManager`)
- Публичный ключ доступен для копирования через Настройки → Безопасность

## [0.1.0] - 2026-02-04

### Added (Добавлено)

#### Основная функциональность
- BLE сканирование устройств Meshtastic
- Подключение к устройству по BLE
- Мониторинг состояния соединения
- Отображение списка узлов сети
- Настройка канала и PSK
- Локальное сохранение черновика настроек

#### UI компоненты
- `ConnectionFragment` — управление подключением
- `StatusFragment` — панель состояния и телеметрия
- `NodesFragment` — список узлов сети
- `SettingsFragment` — конфигурация
- Bottom Navigation для переключения между экранами

#### Bluetooth Layer
- `BleManager` — управление BLE транспортом
- GATT операции через очередь
- Drain loop для FromRadio
- Автоматическое MTU negotiation
- Poll fallback для FromNum уведомлений

#### Repository Layer
- `MeshConnectionRepository` — централизация состояния
- LiveData для реактивного обновления UI
- Обработка FromRadio пакетов
- Парсинг protobuf сообщений

#### Data Models
- `DeviceStatus` — агрегированное состояние устройства
- `NodeInfo` — информация об узлах
- `SettingsDraft` — черновик настроек

#### Storage
- `SettingsStore` — хранение черновика в SharedPreferences

#### Протокол
- Поддержка FromRadio типов: MY_INFO, NODE_INFO, CONFIG, CHANNEL, PACKET, METADATA
- Отправка ToRadio команд
- Admin пакеты для настройки канала/PSK

#### Документация
- `SETUP.md` — установка и настройка окружения
- `USAGE.md` — руководство пользователя
- `ARCHITECTURE.md` — описание архитектуры
- `CONFIGURATION.md` — настройка сети и безопасности
- `TROUBLESHOOTING.md` — устранение неполадок
- `FEATURES.md` — список функций и roadmap
- `FAQ.md` — часто задаваемые вопросы
- `GLOSSARY.md` — глоссарий терминов

### Changed (Изменено)
- Переработан layout `fragment_settings.xml` — отключена анимация hint, добавлены статические заголовки над полями
- Улучшена обработка ошибок в BLE подключении
- Оптимизирована очередь GATT операций

### Fixed (Исправлено)
- Дублирование TextViews в `fragment_status.xml`
- Таймауты GATT операций
- Race conditions в drain loop

### Security (Безопасность)
- PSK хранится локально в SharedPreferences
- Нет передачи данных в интернет
- Отсутствие аналитики и трекинга

## Соглашения о формате

### Типы изменений

- **Added** — новые функции
- **Changed** — изменения в существующей функциональности
- **Deprecated** — функции, которые скоро будут удалены
- **Removed** — удалённые функции
- **Fixed** — исправления ошибок
- **Security** — изменения безопасности

### Версионирование

Формат: `MAJOR.MINOR.PATCH`

- **MAJOR** — несовместимые изменения API
- **MINOR** — обратно совместимые новые функции
- **PATCH** — обратно совместимые исправления

Примеры:
- `0.1.0` — первая MVP версия
- `0.2.0` — добавлен чат (новая функция)
- `0.2.1` — исправлена ошибка в чате (bugfix)
- `1.0.0` — стабильный релиз
